# LINE メッセージ送信アプリ

## 課題の概要

LINE Messaging API を利用して、指定した LINE ユーザーへテキストメッセージを送信する Python プログラムです。
「LINE Messaging API を利用して、シンプルにメッセージを送る機能」の実装課題として作成しました。

## 実装した機能

- `.env` ファイルからチャネルアクセストークンと送信先ユーザーIDを読み込む
- 環境変数が未設定の場合は、分かりやすいエラーメッセージを表示して終了する
- LINE Messaging API の Push Message エンドポイントへテキストメッセージを送信する
- 成功時はステータスコードと成功メッセージを表示する
- 失敗時はステータスコードと LINE API から返されたエラー内容を表示する
- 通信エラー（ネットワーク障害など）も例外処理で分かりやすく表示する

## 使用技術

- Python 3
- LINE Messaging API（Push Message エンドポイント）
- requests（HTTP リクエスト送信用ライブラリ）
- python-dotenv（`.env` ファイル読み込み用ライブラリ）

## 事前準備（LINE 公式アカウントと Messaging API）

このプログラムを使うには、以下の準備が必要です。

1. [LINE Developers](https://developers.line.biz/) でアカウントを作成する
2. プロバイダーと Messaging API チャネル（LINE 公式アカウント）を作成する
3. チャネルの設定画面から **チャネルアクセストークン** を発行する
4. 送信先となる自分の **LINE ユーザーID** を確認する（チャネル基本設定の「あなたのユーザーID」など）
5. 作成した LINE 公式アカウントを、送信先のユーザーが友だち追加しておく

## 環境変数の設定手順

1. `.env.example` をコピーして `.env` を作成します。

   ```bash
   cp .env.example .env
   ```

2. `.env` を開き、実際の値を設定します。

必要な環境変数は以下の2つです。

| 環境変数名 | 内容 |
| --- | --- |
| `LINE_CHANNEL_ACCESS_TOKEN` | LINE Developers で発行したチャネルアクセストークン |
| `LINE_USER_ID` | メッセージの送信先となる LINE ユーザーID |

## ライブラリのインストール方法

```bash
python3 -m pip install -r requirements.txt
```

## プログラムの実行方法

```bash
python3 send_message.py
```

## 成功時に表示される内容

送信に成功すると、ターミナルに以下のように表示され、送信先の LINE にメッセージが届きます。

```
ステータスコード: 200
メッセージの送信に成功しました
```

## 注意事項（重要）

- **`.env` ファイルは絶対に GitHub へ公開（Push）しないでください。**
  チャネルアクセストークンが漏れると、第三者に LINE 公式アカウントを悪用される恐れがあります。
- このプロジェクトでは `.gitignore` に `.env` を登録しているため、通常は Git 管理対象外になります。
- `.env.example` にはダミー値のみを記載し、本物のトークンやユーザーIDは書かないでください。
- アクセストークンやユーザーIDをソースコードへ直接書かないでください。
